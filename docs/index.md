# What's in the name?

**$\mu$Torch** / **utorch** carries a dual meaning:

1. **Understandable**: Every line of code is transparent, heavily annotated, and written for human comprehension rather than complex engine dispatching.
2. **$\mu$ (Micro)**: A minimalist, first-principles implementation that strips away framework bloat down to the core mathematical essentials of automatic differentiation.
