# API Reference

`utorch` is organized into three primary modules:

* [**`utorch.autograd`**](autograd.md): Reverse-mode automatic differentiation engine, computation graph nodes, and the `Tensor` abstraction.
* [**`utorch.nn`**](nn.md): Neural network modules (`Module`, `Parameter`), layers (`Linear`), loss functions, and optimizers.
* [**`utorch.utils`**](utils.md): Data loaders, batching utilities, and computational graph visualization tools.
